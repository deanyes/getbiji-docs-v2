## 编辑器概览

Get笔记编辑器支持富文本和 Markdown 两种模式，可随时切换。

## 富文本模式

默认的编辑模式，通过工具栏快捷操作：

- **加粗** / *斜体* / ~~删除线~~
- 有序列表和无序列表
- 插入图片、链接、表格
- 代码块和行内代码

## Markdown 模式

在设置中开启 Markdown 模式，享受纯文本编辑体验：

```markdown
# 标题
## 二级标题

**加粗** *斜体*

- 列表项 1
- 列表项 2

> 引用文本

`行内代码`
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + B` | 加粗 |
| `Ctrl/Cmd + I` | 斜体 |
| `Ctrl/Cmd + K` | 插入链接 |
| `Ctrl/Cmd + Shift + C` | 代码块 |
| `Ctrl/Cmd + /` | 呼出 AI 助手 |

<Callout type="info">
在移动端，长按编辑区域可弹出快捷操作菜单。
</Callout>

## 插入内容

### 图片

支持以下方式插入图片：

1. 工具栏点击图片图标
2. 直接粘贴剪贴板中的图片
3. 拖拽图片文件到编辑区域

### 表格

点击工具栏的表格图标，选择行列数即可创建。支持拖拽调整列宽。

### 代码块

支持语法高亮，识别超过 100 种编程语言。
